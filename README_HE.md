# UNIGAEA – עדכון מצבי תצוגה

בחלק העליון של האפליקציה מופיעים כעת שלושה כפתורים נפרדים:
- אוטומטי – עוקב אחרי מצב התצוגה של המכשיר.
- בהיר – מצב בהיר קבוע.
- כהה – מצב כהה קבוע.

הבחירה נשמרת במכשיר. מצב האופליין נשמר באמצעות Service Worker, וגרסת המטמון עודכנה כדי שהמכשיר יתקין את הקבצים החדשים.

## התקנה ב-GitHub Pages
החליפו את כל הקבצים בשורש ה-Repository בתוכן החבילה, ואז בצעו Commit changes. אין ליצור Repository חדש. לאחר העלאה, פתחו את האתר עם חיבור אינטרנט ורעננו פעם אחת.
